# Localization (i18n)

## I18N-01 — Switch language
- **Steps**: Open **View → Language**, pick a second language.
- **Expected**: All labels update at once. No leftover strings in the old language.
- **Priority**: Medium
- **Type**: UI

## I18N-02 — Language persists
- **Steps**: Pick a language, restart the app.
- **Expected**: App starts in the chosen language.
- **Priority**: Medium
- **Type**: Regression

## I18N-03 — Missing key fallback
- **Preconditions**: A new feature has no translation yet.
- **Steps**: View it in a non-default language.
- **Expected**: Falls back to English. No `[[MISSING]]` placeholder shown to user.
- **Priority**: Low
- **Type**: Negative
